# 版本记录

## 规则

- 版本格式：`主版本号.次版本号.build号`，从 **0.0.1** 开始。
- **每次正式构建 + 全量测试通过后，build 号 +1**；由维护者（编排者）记录在本文件。
- **主版本号 / 次版本号只在用户明确要求时提高**，平时保持不变。
- 版本号的唯一来源是仓库根的 `VERSION` 文件；CMake、编译器 `--version`、生成的 C 代码都从它读取。
